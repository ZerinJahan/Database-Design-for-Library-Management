# Database-Design-for-Library-Management
Designed and implemented a Library Management System database in Microsoft SQL Server to help librarians manage members, resources, loans, and repayments efficiently, ensuring the structure followed Third Normal Form (3NF) for optimal data organization.
Used T-SQL to create and manage four main tables—Members Info, Library Catalogue, Loan, and Repayment—and developed stored procedures and user-defined functions to handle specific queries and operations as part of the assessment.
